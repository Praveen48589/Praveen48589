### 🧭 About Me

I'm a DevOps & Cloud Engineer focused on turning manual deployment pain into pipelines that just work. My interest sits squarely in **CI/CD and automation** — taking a build from commit to production with as little human intervention (and as few 2am pages) as possible.

- 🔭 **Currently building:** CI/CD pipelines and automated infrastructure workflows
- 🌱 **Currently learning:** Kubernetes · Terraform · AWS · Docker at production depth
- ⚙️ **Core belief:** if a deployment step is manual, it's a future incident waiting to happen
- 💬 **Ask me about:** pipeline design, containerization, or infrastructure automation

### ⚙️ CI/CD & Automation Focus

| Stage | What I work with |
|---|---|
| **Source & Review** | Git, GitHub Actions, GitLab CI |
| **Build & Package** | Docker, Jenkins |
| **Infrastructure** | Terraform, Ansible |
| **Deploy & Orchestrate** | Kubernetes, AWS |
| **Observe & Alert** | Prometheus, Grafana |

**How I think about a pipeline:**
- ✅ Every stage should fail fast and fail loud — no silent breaks discovered in prod
- ✅ Infra changes reviewed like code, not applied by hand from a laptop
- ✅ A pipeline is only "done" once rollback is as automated as rollout
